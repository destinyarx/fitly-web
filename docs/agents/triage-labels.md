# Triage labels

The engineering skills use five canonical triage roles. Local issue files record the matching value in their `Status:` line.

| Skill role | Local status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgment. |
| `wontfix` | `wontfix` | The issue will not be acted on. |

When a skill names a triage role, use the matching local status from this table.
